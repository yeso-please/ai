# 데이터 카드: 평가·학습 데이터 (#3)

취향 임베딩 추천을 **실제 여행자 데이터**로 학습·평가하기 위해, AI Hub 국내 여행로그의 방문지를 TourAPI 관광지와 연결한 데이터다. 원본과 산출물은 모두 `data/raw/`, `data/interim/`에 두며 **커밋하지 않는다.**

## 출처와 이용 조건

| 데이터 | 출처 | 이용 조건 |
|---|---|---|
| 국내 여행로그 2023 (수도권 71776, 동부권 71778, 서부권 71779, 제주도 및 도서지역 71780) | [AI Hub](https://aihub.or.kr) | 인공지능 학습용. 상업적 이용은 별도 협의. **제3자 제공·재배포 금지.** 결과물에 출처 표기 의무 |
| 관광 콘텐츠 목록·분류체계 코드 | 한국관광공사 TourAPI (KorService2) | 공공데이터포털 이용 조건. 콘텐츠별 저작권 유형 `cpyrhtDivCd`(Type1/Type3) 확인 |

**출처 표기**: AI Hub 이용정책상 결과물(2차 저작물 포함)에 **한국지능정보사회진흥원의 사업 결과임**과 사용한 데이터셋 이름("국내 여행로그 데이터")을 밝혀야 한다. 발표·보고서에 넣을 정확한 문구는 [AI Hub 이용정책](https://www.aihub.or.kr/intrcn/guid/usagepolicy.do)의 최신 안내를 확인해 정한다.

## 만드는 방법

```bash
python scripts/extract_aihub.py                     # 분할 압축 병합, 한글 파일명 복구 → data/raw/aihub/<권역>/<TL|VL>/
TOUR_API_KEY_FILE=<키 파일> python scripts/collect_tourapi.py --regions 11 28 41 26 27 30 31 36110 43 44 47 48 50 51 52 12
TOUR_API_KEY_FILE=<키 파일> python scripts/collect_tourapi.py --class-codes data/reference/tourapi_lcls_codes.csv
python scripts/match_aihub_tourapi.py --visits <tn_visit_area_info_*.csv> --tourapi data/raw/tourapi/region_*.csv \
    --out data/interim/match_<권역>_<TL|VL>.csv       # 권역·분할마다
PYTHONPATH=scripts python scripts/build_eval_dataset.py --review 100
```

- TourAPI 지역 조회는 **법정동 코드 `lDongRegnCd`**로 한다. 옛 `areaCode`는 빈 콘텐츠가 많다(예: 경복궁). 강원 51, 전북 52, 세종 36110, 광주·전남 통합 12.
- 분류는 새 체계 `lclsSystm1~3`을 쓴다(100% 채워짐). 옛 `cat1~3`은 31%만 있다.
- 호출 수: 목록 92회 + 코드표 1회.

## 매칭

AI Hub 방문지 좌표 반경 안의 TourAPI 후보 중 이름이 가장 비슷한 것을 고른다.
- 대상 방문: 관광지 성격 유형(자연, 역사·유적, 문화시설, 상업지구, 레저, 테마시설, 산책로, 축제, 체험). 집·숙소·식당·역 등 제외
- TourAPI 후보: 관광지(12), 문화시설(14), 레포츠(28), 쇼핑(38). 축제(15)는 장소가 아니라 제외
- 이름 정규화(괄호·공백·기호 제거) 후, 완전 일치 1.0 / 포함 관계 0.7~1.0 / 그 외 문자열 유사도
- "○○점", "야간개장", "축제" 등으로 끝나는 매장·행사 이름이 본 관광지에 붙지 않게 거른다
- **매칭 기준: 반경 500m 이내, 유사도 0.8 이상** (`MATCH_MAX_DIST_M`, `MATCH_MIN_SIM`)

| 권역 | Training 방문 매칭률 | Validation 방문 매칭률 |
|---|---|---|
| 수도권 | 61.8% | 62.1% |
| 동부권 | 66.9% | 65.1% |
| 서부권 | 65.5% | 62.3% |
| 제주도 및 도서지역 | 62.8% | 64.2% |

**정확도**: 검수 표본 100건(권역별 25건, `data/interim/review/match_review.csv`)으로 확정 예정. 사전 눈 검수 60건에서는 같은 장소 약 87%, 큰 시설 안 매장·부속 시설 포함 약 97%였다.

| 항목 | 값 | 의미 확인 |
|---|---|---|
| 여행 스타일 1 | 1~7 | 자연 ↔ 도시 (공식 코드표) |

| 여행 미션 | 코드 목록 | 공식 코드표 'MIS' (쇼핑, 역사 유적지, SNS 인생샷, 캠핑 등 28종) |

## 한계

- **만족도 쏠림**: 관광지 방문 중 5점 약 50%, 4점 약 37%, 3점 이하 약 14%. 부정 사례가 적다.
- **안 간 곳 ≠ 싫은 곳**: 방문하지 않은 관광지는 몰라서 안 갔을 수 있다. 정밀도보다 순위 지표(nDCG, Recall)가 맞다.
- **매칭 누락**: 방문의 약 1/3은 TourAPI와 연결되지 않는다. 작은 가게·동네 공원·명칭이 크게 다른 곳이 주로 빠진다. 유명 관광지 쪽으로 치우칠 수 있다.
- **쇼핑 비중**: 수도권은 상업지구 방문이 많고, TourAPI 쇼핑은 체인점이 대부분이다. 평가 기본값은 쇼핑 제외.
- **POI 정보 불일치**: AI Hub의 `POI_ID/POI_NM`은 방문지명과 안 맞는 행이 있어 쓰지 않는다.
- **공식 기준 수치**: AI Hub 문서의 추천 모델 수치(Recall@5 61.4% 등)는 평가 조건이 명시되지 않아 직접 비교하지 않는다(#5에서 같은 조건으로 재현).
