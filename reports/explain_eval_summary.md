# 코스 소개 생성 평가 요약 (#7)

- 실행일: 2026-10-09
- 생성 모델: `gemini-flash-lite-latest`, 프롬프트 `course-explain-v2`, 임베딩 `mminilm-l12-v1`
- 방법: `scripts/explain_eval.py --n 30 --seed 42`. 소개글이 있는 관광공사 추천코스 30개에 **장소 목록만** 주고 생성한다. 그 코스 자신은 문체 예시 검색에서 뺀다
- LLM에는 TourAPI 공개 데이터(코스 장소 이름·분류·지역·설명)만 보낸다. 회원 정보는 쓰지 않는다

## 자동 지표

| 지표 | 사실 확인 끔 (기본) | 사실 확인 켬 (`--check-claims`) | 1차 시험 (5개, 끔) |
|---|---:|---:|---:|
| 소개글이 LLM 생성으로 통과 | **90%** (27/30) | 57% (17/30) | 40% |
| 제목 통과 | 90% | 93% | 100% |
| 장소별 이유 통과 (평균) | 89% | 93% | 100% |
| 소개글 ↔ 코스 장소 임베딩 유사도: 관광공사 | 0.404 | 0.420 | 0.451 |
| 소개글 ↔ 코스 장소 임베딩 유사도: 생성 | 0.344 | 0.365 | 0.425 |

- 끔: 탈락 3건은 모두 형식 검증(`FORMAT`) 실패다. 호출 실패는 0건.
- 켬: 형식 2건 + **사실 확인(`UNSUPPORTED`) 11건**이 규칙 문장으로 대체됐다.
- 유사도는 LLM이 통과한 소개글만의 평균이다. 생성 소개글이 관광공사 글보다 코스 장소와 덜 가깝다. 장소를 덜 구체적으로 언급한다는 뜻이다.

생성 예시 (보령 은행마을 → 신경섭 전통가옥 → 오서산 → … → 무창포어촌체험마을)

> **관광공사**: 보령 청라면의 은행마을은 가을이 탐스럽다. 10월이면 마을 전역이 노랗게 물들기 시작하며 '황금빛 향연'을 만들어낸다. …
>
> **생성**: 노랗게 물든 은행나무 길을 지나 서해의 바람을 따라 걸어보자. 고즈넉한 고택과 억새가 반기는 산길을 거쳐 붉게 물드는 바다까지 이어지는 발걸음마다 깊은 계절의 숨결이 스며든다.

## 사실 확인 단계를 켤지

사실 확인이 근거에 없다고 판단한 표현 11건을 직접 보면 세 종류가 섞여 있다.

| 종류 | 예 | 판단 |
|---|---|---|
| 근거에 없는 사실 | "태백산맥이 두르는 낙동강 물결"(안동), "온천 온기로 하루를 마무리한다"(고성) | 잡아야 한다 |
| 계절·감각 묘사 | "은행나무 잎이 노랗게 물드는 종로의 길", "푸른 소나무", "오래된 시장의 공기" | 사실 주장이 아니라 분위기 표현. 관광공사 글도 쓰는 방식이다 |
| 동선 요약 | "부천 물 박물관과 부천식물원을 잇는 길", "속초에서 시작해 … 강릉 통일공원에 닿는 동안" | 장소 목록 자체가 근거다. 잘못 걸렸다 |

**권장: 기본은 끈 채로 둔다.** 진짜 오류를 잡는 대신 통과율이 90% → 57%로 떨어지고, 걸린 것의 절반 이상이 묘사·동선 요약이다. 켜려면 판정 프롬프트가 "계절·감각 묘사와 장소 목록에서 나온 동선은 근거로 본다"를 알도록 고친 뒤 다시 잰다. 최종 결정은 아래 사람 평가의 "사실 정확성" 점수를 보고 한다.

## 참고

- 평가에 쓴 색인은 지점 설명 정리(`build_descriptions.py`의 `\n`·`<br>` 제거) 전에 만든 것이다. 정리 뒤 색인을 다시 만들었다(코스 1,068개, 소개글 1,046개). 문체 예시 검색 순위가 일부 바뀔 수 있지만 위 결론에는 영향이 작다.
- 서버는 `COURSE_INDEX_PATH`(기본 `data/interim/course_index/mminilm-l12-v1.npz`)에 색인이 있을 때만 문체 예시를 쓴다. Docker 이미지에는 `data/interim/`이 들어가지 않으므로 배포 환경에서 쓰려면 이 파일을 마운트해야 한다.
